# AgriPak / AgriVoice

FastAPI backend + frontend for Pakistani farmers (auth, AgriVoice chat, leaf-scan, weather, mandi rates).

Run locally:
```
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 7860
```
